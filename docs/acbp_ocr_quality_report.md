## 3. Structural Table Recovery Methodology

The document presents dense scanned tabular grids across Pages 2 through 13. To recover table structure as faithfully as possible without guessing or hallucinating cells, the engine employs a hybrid morphological and spatial segmentation pipeline:

```
Raw Scanned Page (200 DPI)
         │
         ├──► PyMuPDF Text Layer ──► Native Watermark Capture ('native_pdf')
         │
         ├──► OpenCV Adaptive Thresholding & Morphological Filtering
         │         ├─► Vertical Kernel   ──► Column Boundaries (5 columns)
         │         └─► Horizontal Kernel ──► Row Dividers (20–33 dividers)
         │
         └──► EasyOCR Inference (CPU) ──► Bounding Boxes, Text & Confidence
                   │
                   ▼
      Spatial Cell Intersection & Line-Clustered Reading Order
                   │
                   ▼
       Structured Row Objects + Uncertainty & Anomaly Flags
```

1. **Vertical Column Partitioning**:
   - Column 0: `S. No.` (or `Sr. No.`)
   - Column 1: `Course Name` (or `Division` on Page 13)
   - Column 2: `Competency` (or `Name of the Officer` on Page 13)
   - Column 3: `Duration` (or `Designation` on Page 13)
   - Column 4: `Course Creator` (or `Email` on Page 13)
2. **Row Segmentation & Duration Anchor Calibration**:
   - For regular grids (Pages 3–12), horizontal lines detected via morphological kernels determine cell bounds.
   - For Page 2 (where faint scan lines occur near the footer), the 23 verified duration timestamps (`HH:MM:SS`) serve as vertical row anchors, ensuring all 23 course rows are cleanly isolated without accidental row merging.
3. **Reading Order Preservation**:
   - Multi-line course titles and organization names (e.g. `National E-Governance Division (NeGD), MeitY, Govt of India`) are clustered into horizontal sub-lines (`y_thresh = 14 px`) and sorted left-to-right to preserve syntactic coherence.
4. **Uncertainty Flagging (Zero Hallucination)**:
   - Low confidence cells (`confidence < 0.50`) are marked with `is_uncertain: true` and flagged with specific reasons (`low_average_confidence`).
   - Unconventional duration formats (e.g., `01.334:00` or `Oo.50.00` where 'O' replaced '0') are flagged with `unconventional_duration_format`.
   - Any unrecognized competency tag is preserved verbatim and flagged with `unrecognized_competency_type`.
